## 4. Dev.to — Blog Post

**Title:** I Built 44 Free Online Tools in Vue 3 — Here's What I Learned

**Body (outline):**

### Intro
Side projects come in many forms. For me, it was a toolbox — a collection of 44 online utilities that I use in my daily workflow. Three weeks of building, a few hundred TypeScript errors, and one very cluttered i18n file later, here's what I learned.

### Why build it?
- Tired of hopping between 20 different tool sites
- Wanted something ad-free, no sign-up, no tracking
- Good excuse to practice Vue 3 + TypeScript

### Architecture
- Vue 3 Composition API + TypeScript
- Vite for build (blazing fast)
- vue-i18n for localization (zh-CN / EN)
- All client-side, no backend
- ~600 modules, ~1.7MB main chunk (mostly unavoidable with 44 tools)

### i18n Lessons
- Per-tool namespace approach worked well
- Type-safe i18n wrapper (`useI18nt`) prevents key typos
- Maintaining 44 tools × 2 languages = 88 sets of translation keys. Scripts helped.

### Standout Tools
- The Wubi learning tool (Chinese input method) was the most complex — 4 tabs (query, keyboard, practice, characters), 500+ character database
- The CRC calculator supports 13 algorithms from CRC-1 to CRC-32, all pure TypeScript lookup tables
- The Chinese ID card lookup validates 18-digit numbers with checksum and extracts birthplace/birthday

### What's Next
- Better offline support via service workers
- More conversion categories
- Would like to hear from other devs what tools they'd add

### Links
GitHub (if open source) | https://toolbox.mzxy.top

## 8. GrowthHackers / Indie Hackers — Community Post

**Title:** How I built 44 free online tools in 3 weeks as a side project

**Body:**
Three weeks ago I set out to build something useful — a single website with all the online tools I use daily. No ads, no sign-up, no tracking.

The hardest part wasn't building 44 tools — it was keeping the codebase organized. Here's what worked:

1. **Component generator scripts** — Writing 44 components by hand would've been insane. I built Node.js scripts that generate Vue components from templates.

2. **i18n from day one** — Internationalization is a pain to retrofit. Starting with `vue-i18n` and a type-safe wrapper saved me hours.

3. **Pure client-side** — No backend means zero hosting costs beyond static file serving. The site loads fast and works offline.

4. **Features users actually want** — The most-used tools so far: JSON parser, base64 encoder, color converter, and surprisingly — the Wubi Chinese input learning tool.

Check it out: https://toolbox.mzxy.top

Tech stack: Vue 3 + Vite + TypeScript. All free, open to feedback!
